Full-stack platform for a B2B luxury furniture brand

A full-stack home decor and furniture platform. The React (Vite) frontend runs on Vercel and talks to a Spring Boot REST API on Render, backed by MongoDB. JWT authentication with role-based access protects an admin dashboard where the owner adds, edits and deletes listings with image uploads, pricing and inventory.

Media is served from Cloudflare R2, and the custom domain is mapped through Cloudflare DNS. The mobile-first UI built with Tailwind CSS and React hooks has a dynamic catalog with filtering and search.
